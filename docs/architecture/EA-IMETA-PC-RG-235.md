## Purpose

Establish the authoritative mandatory procedural verification layer for RG-234, determining whether the substantive validation of RG-233 verification was correctly performed, evidenced, authorized, decided, recorded and implemented.

## Core Principle

RG-234 determines whether the RG-233 verification is substantively effective. RG-235 verifies that RG-234's validation of that verification was correctly performed and implemented.

```text
RG-232 → VALIDATE
RG-233 → VERIFY
RG-234 → VALIDATE
RG-235 → VERIFY
```

```text
RG-234 SUBSTANTIVE VALIDATION
        ↓
RG-235 PROCEDURAL VERIFICATION
        ↓
WAS RG-234 CORRECTLY PERFORMED?
```

A positive RG-234 validation SHALL NOT automatically prove that RG-234 was correctly verified.

```text
RG-234 VALIDATION
+ VALID TRIGGER
+ CORRECT RG-233 BASIS
+ CURRENT STATE
+ VERIFICATION EFFECT
+ CURRENT OUTCOME
+ VERIFICATION INTEGRITY
+ VALIDATION EFFECTIVENESS
+ CONTROLS + RISK
+ DEPENDENCIES + OBLIGATIONS
+ CONDITIONS + PERSISTENCE
+ INVALIDATING CONDITIONS
+ EVIDENCE + AUTHORITY + SCOPE + CRITERIA
+ DECISION + RECORDING + COMMUNICATION + IMPLEMENTATION
= VERIFIED RG-234 VALIDATION
```

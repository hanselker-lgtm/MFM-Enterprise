# 1. Purpose

The purpose of this document is to define the mandatory standards governing Enterprise Reference Data Management throughout the MFM Enterprise Platform.

Enterprise Reference Data Management ensures that enterprise reference data is defined, governed, maintained, versioned and distributed consistently across the enterprise while preserving accuracy, integrity, traceability and compliance with Enterprise Architecture.

---

# 2. Scope

This guide applies to

- Reference Data Domains
- Reference Data Classification
- Reference Data Ownership
- Reference Data Governance
- Reference Data Lifecycle
- Reference Data Distribution
- Reference Data Versioning
- Governance
- Compliance

All Enterprise Reference Data Management implementations shall comply with this guide.

---

# 4. Reference Data Management Principles

Enterprise Reference Data Management implementations shall follow these principles.

- Standardized Reference Data
- Single Controlled Source
- Controlled Versioning
- Enterprise Consistency
- Complete Traceability
- Controlled Distribution
- Technology Independence
- Centralized Governance

Reference Data Management implementations shall remain independent of business logic.

# 22. Error Handling

Enterprise Reference Data Management implementations shall handle reference data management-related exceptions consistently.

Implementations shall

- classify reference data classification failures
- classify lifecycle management failures
- classify version management failures
- classify reference data quality failures
- classify distribution failures
- preserve complete auditability
- notify governance authorities

Reference Data Management exceptions shall never compromise enterprise architecture, reference data integrity, traceability, governance or compliance.

---

# 23. Dependency Rules

Enterprise Reference Data Management implementations may depend upon

- approved master data management services
- approved metadata management services
- approved data governance services
- approved integration services
- approved security services
- approved enterprise infrastructure
- approved governance services

Enterprise Reference Data Management implementations shall never depend upon

- Presentation implementations
- Workflow implementations containing business logic
- Domain implementations
- Repository implementations across capability boundaries
- Business Services
- Unapproved external reference data providers

Reference Data Management capabilities shall remain centralized wherever practical.

---

# 24. Compliance Checklist

An Enterprise Reference Data Management implementation is compliant when

- Reference data domains are documented.
- Reference data classification is implemented.
- Reference data lifecycle management is implemented.
- Reference data versioning is maintained.
- Reference data quality is continuously monitored.
- Reference data distribution is controlled.
- Reference data verification is performed.
- Governance requirements are fulfilled.
- Audit requirements are satisfied.
- Documentation is complete.

---

# 25. Common Anti-Patterns

The following practices are prohibited.

## Missing Reference Data Ownership

Reference data shall never exist without documented ownership and stewardship.

---

## Duplicate Reference Data Definitions

The same enterprise reference value shall never have multiple conflicting definitions.

---

## Uncontrolled Reference Data Changes

Reference data shall never be modified outside approved governance and version management procedures.

---

## Poor Reference Data Quality

Reference data shall never be distributed without validation for completeness, consistency and correctness.

---

## Unauthorized Reference Data Distribution

Reference data shall never be distributed without documented authorization and governance approval.

---

## Reference Data Management Logic Inside Business Components

Business components shall never implement independent reference data management mechanisms outside approved Enterprise Reference Data Management services.

---

The Enterprise Reference Data Management Architecture Standards Guide defines the mandatory standards governing Enterprise Reference Data Management throughout the MFM Enterprise Platform.

Its purpose is to ensure that enterprise reference data is defined, governed, maintained, versioned and distributed consistently across the enterprise while preserving accuracy, integrity, traceability and compliance with Enterprise Architecture.

All Enterprise Reference Data Management implementations developed for the MFM Enterprise Platform shall comply with this guide.

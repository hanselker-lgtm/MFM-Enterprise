# 6. Evidence Boundary

The following remains mandatory:

```text
Governance Model
≠
Organizational Implementation

Control Definition
≠
Control Operation

Control Operation
≠
Control Effectiveness

Compliance Model
≠
Compliance Certification

Assurance Model
≠
Assurance Result
```

Therefore, N5 completion shall not be interpreted as certification that all governance capabilities are operationally effective.

---

# 7. Conditions

The following controlled conditions remain attached to the recommendation:

```text
COND-N5-01
Actual authority and accountability assignments must remain evidence-based.

COND-N5-02
Decision-right assignments must remain evidence-based.

COND-N5-03
Control operation and effectiveness must not be inferred from control definitions.

COND-N5-04
Compliance status must not be inferred without appropriate evidence.

COND-N5-05
Assurance effectiveness must not be inferred from the existence of an assurance model.

COND-N5-06
Organizational governance implementation remains outside the architectural completion claim unless independently evidenced.

COND-N5-07
N6 remains separately controlled and is not automatically authorized by N5 completion.
```

These are control boundaries, not automatic deficiencies.

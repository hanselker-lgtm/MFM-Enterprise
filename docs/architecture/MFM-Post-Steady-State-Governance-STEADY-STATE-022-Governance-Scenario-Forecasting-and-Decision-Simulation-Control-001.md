# 1. Purpose

STEADY-STATE-022 establishes the controlled mechanism for using scenarios, forecasts, simulations and what-if analysis to examine possible future states and decision alternatives.

The purpose is to improve forward-looking governance without confusing:

```text
SCENARIO
≠
FORECAST

FORECAST
≠
FACT

SIMULATION
≠
ACTUAL OUTCOME

MODELLED OUTCOME
≠
GUARANTEED OUTCOME

OPTION
≠
DECISION
```

The operating sequence is:

```text
QUESTION
↓
BASELINE
↓
ASSUMPTIONS
↓
SCENARIO / MODEL
↓
SIMULATION / FORECAST
↓
RESULTS
↓
UNCERTAINTY
↓
OPTION ASSESSMENT
↓
AUTHORIZED DECISION
↓
ACTUAL OUTCOME
↓
BACK-TEST / LEARNING
```

---

# 2. Core Principle

Forward-looking analysis shall remain explicitly separated from observed reality.

```text
OBSERVED STATE
≠
ASSUMED STATE

ASSUMPTION
≠
FACT

SCENARIO
≠
PREDICTION

FORECAST
≠
CERTAINTY

SIMULATION
≠
EVIDENCE OF ACTUAL PERFORMANCE

MODEL RESULT
≠
AUTHORIZED ACTION
```

# 4. Scenario

A scenario is a structured representation of a possible future or alternative operating condition.

A scenario should identify:

```text
Scenario ID
Purpose
Time Horizon
Starting State
Assumptions
External Conditions
Internal Conditions
Key Variables
Constraints
Expected Relationships
Owner
Version
Status
```

---

# 5. Scenario Boundary

A scenario is not automatically a prediction.

```text
SCENARIO
=
PLAUSIBLE / STRUCTURED POSSIBILITY
```

It shall not be presented as:

```text
CERTAIN FUTURE
```

unless separately supported by an appropriate evidentiary basis.

---

# 6. Scenario Types

Scenarios may include:

```text
BASE CASE
UPSIDE
DOWNSIDE
STRESS
DISRUPTION
TRANSFORMATION
CONTINUITY
RECOVERY
```

The selected scenario set shall be proportionate to the decision need.

---

# 7. Scenario Diversity

Where material uncertainty exists, a single scenario shall not automatically be treated as sufficient.

Alternative scenarios may be required to expose:

```text
Uncertainty
Range
Sensitivity
Tail Risk
Dependency
Strategic Choice
```

---

# 8. Baseline

Every material scenario or simulation should identify its baseline.

The baseline should define:

```text
Current State
Reference Date
Known Conditions
Known Constraints
Known Dependencies
Known Performance
Known Assumptions
```

Baseline integrity remains subject to STEADY-STATE-011.


---

# 10. Assumption Classification

Assumptions may be classified as:

```text

SUPPORTED
ESTIMATED
HYPOTHETICAL
UNKNOWN
```

The classification shall remain visible in decision-support material.

---

# 11. Assumption Risk

Material assumption risk exists where:

```text
SCENARIO RESULT
depends materially on
ASSUMPTION
```

The sensitivity to that assumption shall be assessed where practical.

---

# 12. Forecast

A forecast is a structured estimate of a future state based on specified information, assumptions and methodology.

A material forecast should identify:

```text
Forecast ID
Purpose
Method
Input Data
Time Horizon
Assumptions
Output
Uncertainty
Limitations
Owner
Version
Status
```

---

# 13. Forecast Horizon

Forecasts shall explicitly state their horizon:

```text
SHORT TERM
MEDIUM TERM
LONG TERM
```

Exact periods shall be defined by the applicable use case.

---

# 14. Forecast Uncertainty

Forecasts should communicate uncertainty through appropriate means such as:

```text
Range
Confidence Interval
Probability
Sensitivity
Alternative Scenarios
Qualitative Uncertainty
```

The chosen method shall match the analytical method.

---

# 15. Forecast Drift

Forecast accuracy shall be reviewed where material.

Possible causes of forecast drift:

```text
Changed Conditions
Changed Relationships
Poor Data
Changed Strategy
Structural Break
Model Drift
Unanticipated Event
```

---

# 16. Simulation

A simulation is a controlled representation of system behavior under specified conditions.

A simulation should define:

```text
Simulation ID
Purpose
Model
Starting State
Inputs
Rules
Constraints
Time Horizon
Outputs
Assumptions
Limitations
Owner
Version
```

---

# 17. Simulation Boundary

Simulation outputs are model-generated results.

```text
SIMULATED OUTCOME
≠
OBSERVED OUTCOME
```

They shall not be used as evidence that an event actually occurred.

---

# 18. What-If Analysis

What-if analysis evaluates the implications of changing one or more assumptions or conditions.

The structure is:

```text
BASELINE
↓
CHANGE VARIABLE
↓
RUN ANALYSIS
↓
COMPARE
↓
ASSESS IMPLICATION
```

---

# 19. Sensitivity Analysis

Sensitivity analysis identifies which assumptions or variables materially influence results.

Potential classifications:

```text
LOW SENSITIVITY
MEDIUM SENSITIVITY
HIGH SENSITIVITY
CRITICAL SENSITIVITY
```

---

# 20. Stress Testing

Stress testing examines system behavior under adverse but relevant conditions.

```text

Resource Loss
Supplier Failure
System Failure

Strategic Disruption
Regulatory Change
External Shock
```

---

# 21. Stress Test Boundary

A stress scenario shall not be interpreted as a prediction that the stressed condition will occur.

Its purpose is to assess:

```text
ROBUSTNESS
RESILIENCE
VULNERABILITY
RECOVERY
```

# 23. Scenario Incomparability

Scenarios should not be compared directly where:

```text
Different Scope
Different Time Horizon
Different Definitions
Different Baselines
Different Units
Different Assumptions
```

would make the comparison misleading.

# 30. Scenario Completeness

A scenario set should be assessed for whether it adequately covers:

```text

Adverse
Favorable
Disruptive
Uncertain
```

---

# 31. Tail Risk

Where relevant, scenario analysis should consider low-probability / high-impact outcomes.

Tail-risk scenarios shall be clearly distinguished from expected cases.

---


# 68. Final STEADY-STATE-022 Statement

> **STEADY-STATE-022 establishes the controlled mechanism for scenarios, forecasting and decision simulation. It enables governance to examine possible futures, alternative conditions, stress states and decision options while maintaining a strict distinction between observed facts, assumptions, scenarios, forecasts, simulations and actual outcomes. It provides controlled forward-looking analysis without granting simulated or forecast results autonomous decision authority.

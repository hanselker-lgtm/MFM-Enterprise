# 1. Purpose

The purpose of the MFM Enterprise Architecture Intelligence Security Operating Architecture Framework is to establish an operational security architecture that protects Intelligence capabilities, information, models, platforms, processes and outcomes against threats, misuse and unauthorised access.

The Intelligence Security Operating Architecture Framework shall provide:

- security operating principles
- identity security frameworks
- access control structures
- information security models
- data protection structures
- cyber security models
- threat management structures
- vulnerability management models
- security monitoring structures
- security incident structures
- security automation structures
- security evolution models
- maturity assessment
- operating model

The framework provides the foundation for secure, protected and continuously improving Intelligence operations.

---

# 2. Scope

The Intelligence Security Operating Architecture Framework covers:

- Enterprise Intelligence Security Operating Model

# 3. Intelligence Security Operating Architecture Principles

The Intelligence Security Operating Architecture Framework shall follow these principles.

---

## Principle 1 – Security by Design

Security shall be integrated into Intelligence capabilities from the beginning.

---

## Principle 2 – Confidentiality

Information shall be protected against unauthorised access.

---

## Principle 3 – Integrity

Information and Intelligence capabilities shall maintain correctness and trustworthiness.

---

## Principle 4 – Availability

Security controls shall support operational availability.

---

## Principle 5 – Least Privilege

Access shall be limited according to defined requirements.

---

## Principle 6 – Continuous Security Monitoring

Security condition shall be continuously observed.

---

## Principle 7 – Continuous Security Evolution

Security capability shall continuously improve.

---

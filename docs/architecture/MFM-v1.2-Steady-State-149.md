# 1. Purpose

This document establishes the one-hundred-and-forty-ninth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-148 – Enterprise Infrastructure Architecture & Infrastructure Operations, Compute, Server, Storage, Virtualization, Operating Systems, Cloud Infrastructure, Infrastructure Security, Infrastructure Monitoring, Infrastructure Performance, Infrastructure Capacity, Infrastructure Availability, Infrastructure Resilience, Infrastructure Backup, Infrastructure Recovery, Infrastructure Lifecycle, Infrastructure Technical Debt & Infrastructure Assurance.

The purpose is to establish the permanent enterprise operating model for network strategy, network governance, network architecture, network segmentation, routing, switching, wireless, LAN, WAN, SD-WAN, Internet connectivity, DNS, DHCP, IP address management, network security, network monitoring, network observability, network performance, network capacity, network availability, network resilience, network redundancy, network backup, network recovery, network lifecycle, network technical debt, network suppliers, network compliance, network exceptions, network remediation, network assurance, network metrics, network dashboards, network maturity and continual enterprise network capability improvement.

The central objective is:

> **MFM must govern enterprise networks as secure, standardized, observable, performant, resilient and lifecycle-managed communication foundations that provide reliable connectivity between users, applications, data, infrastructure, cloud services, partners and external services.**

# 3. Network Governance Objective

The primary objective is:

> **Establish clear authority, ownership, architecture, standards, security requirements, operational responsibilities, lifecycle controls and assurance for enterprise networks.**

# 4. Network Architecture Objective

The primary objective is:

> **Provide standardized, secure, scalable, observable and resilient connectivity across enterprise locations, users, applications, infrastructure, cloud services and external parties.**

# 5. Network Operations Objective

The primary objective is:

> **Operate networks reliably through disciplined configuration, monitoring, performance, capacity, availability, incident, problem, change and recovery management.**

# 6. Network Security Objective

The primary objective is:

> **Protect network connectivity, traffic, segments, interfaces, devices and services against unauthorized access, interception, manipulation and disruption.**

# 7. Network Resilience Objective

The primary objective is:

> **Ensure critical network services can tolerate failures and recover within defined business and service requirements.**

# 8. Network Assurance Objective

The primary objective is:

> **Provide reliable evidence that network architecture, security, operations, resilience and lifecycle controls operate effectively.**

# 1. Purpose

The purpose of the MFM Enterprise Architecture Intelligence Transformation Architecture Framework is to establish a structured transformation architecture that enables controlled evolution from current Intelligence capability to future Intelligence capability.

The Intelligence Transformation Architecture Framework shall provide:

- transformation reference model
- current state architecture
- future state architecture
- transition architecture
- transformation roadmap
- change architecture
- migration architecture
- capability transformation model
- technology transformation model
- organisation transformation model
- process transformation model
- culture transformation model
- transformation governance model
- transformation metrics model
- transformation maturity model
- transformation blueprint

The framework provides the foundation for controlled, measurable and continuously improving Intelligence transformation.

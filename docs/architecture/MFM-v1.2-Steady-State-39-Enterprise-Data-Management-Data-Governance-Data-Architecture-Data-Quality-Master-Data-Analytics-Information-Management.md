# 1. Purpose

This document establishes the thirty-ninth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-38 – Enterprise Technology Infrastructure, Cloud, Network, End-User Computing, Platform Services & Infrastructure Operations.

The purpose of this document is to establish the permanent enterprise operating model for data governance, data management, data architecture, information management, data ownership, data stewardship, data quality, master data, reference data, metadata, data lineage, data lifecycle, data classification, data protection, data integration, analytical data, business intelligence, reporting data, data platforms, data retention, data archival, data deletion, data sharing, data access, data assurance and continual data improvement.

The central objective is:

> **MFM data and information must be governed as strategic enterprise assets so that data remains accurate, trusted, secure, accessible to authorized users, appropriately retained and capable of supporting business operations, reporting, analytics, decision-making and regulatory obligations.**

# 113. Definition of Ready

A data, information or analytics work item is Ready when:

- The data domain, dataset, data product, quality issue, model, interface, report, analytical requirement, access request, lifecycle event, finding, exception or improvement is clearly identified.
- Ownership, purpose, classification, quality, security, privacy, retention, architecture, integration and business requirements are known.
- Processing, validation, access, evidence, approval and acceptance requirements are defined.

---

# 1. Purpose

This document establishes the one-hundred-and-forty-first document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-140 – Enterprise Infrastructure Architecture & Infrastructure Operations, Infrastructure Governance, Compute, Storage, Virtualization, Data Center, Cloud Infrastructure, Infrastructure Security, Infrastructure Monitoring, Infrastructure Capacity, Infrastructure Resilience, Infrastructure Recovery, Infrastructure Lifecycle & Infrastructure Assurance.

The purpose is to establish the permanent enterprise operating model for network strategy, network governance, network architecture, network ownership, connectivity, routing, switching, DNS, DHCP, IP address management, wireless networking, remote access, network security, firewalls, load balancing, network monitoring, network logging, network observability, network performance, network capacity, network resilience, network recovery, network lifecycle, network suppliers, network compliance, network exceptions, remediation, network assurance, metrics, dashboards, maturity and continual enterprise network capability improvement.

The central objective is:

> **MFM must govern enterprise networking as a controlled, secure, resilient, observable, performant and lifecycle-managed foundation that provides reliable connectivity between users, applications, data, infrastructure, cloud services, sites and external parties.**

# 3. Network Governance Objective

The primary objective is:

> **Establish clear authority, ownership, architecture, standards, security requirements, operational responsibilities, lifecycle controls and assurance for enterprise networking.**

# 4. Network Architecture Objective

The primary objective is:

> **Provide coherent connectivity, routing, switching, addressing, wireless, remote access and security foundations supporting enterprise users, applications, data, infrastructure, cloud and services.**

# 5. Network Operations Objective

The primary objective is:

> **Operate network services reliably through disciplined monitoring, configuration management, performance management, capacity management, incident management, problem management, change management and recovery.**

# 6. Network Security Objective

The primary objective is:

> **Protect network connectivity, traffic, infrastructure, management interfaces and connected services against unauthorized access, compromise, interception and disruption.**

# 7. Network Resilience Objective

The primary objective is:

> **Ensure critical network services can withstand equipment, circuit, site, power, cloud, provider, configuration and security failures and recover within defined service requirements.**

# 8. Network Assurance Objective

The primary objective is:

> **Provide reliable evidence that network architecture, security, operations, resilience, lifecycle and governance controls operate effectively.**

# 114. Final Resilience Principle

# 116. Final Assurance Principle

# 117. Final Improvement Principle

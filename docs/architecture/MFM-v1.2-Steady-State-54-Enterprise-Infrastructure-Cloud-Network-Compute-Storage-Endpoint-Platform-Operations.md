# 1. Purpose

This document establishes the fifty-fourth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-53 – Enterprise Application Management, Software Lifecycle, DevSecOps, Architecture, Testing & Release Engineering.

The purpose is to establish the permanent enterprise operating model for infrastructure, cloud, network, compute, storage, endpoints, platform services, infrastructure architecture, infrastructure lifecycle, capacity, availability, performance, configuration, monitoring, patching, vulnerability management, backup, recovery, infrastructure security, platform engineering, virtualization, container platforms, identity infrastructure, connectivity, remote access, endpoint management, infrastructure automation, infrastructure-as-code, environment management, infrastructure support, infrastructure continuity, supplier infrastructure, operational assurance, infrastructure metrics, infrastructure maturity and continual infrastructure improvement.

The central objective is:

> **MFM must provide secure, resilient, scalable, supportable and well-governed infrastructure and platform capabilities that reliably support applications, services, data and business operations throughout their lifecycle.**

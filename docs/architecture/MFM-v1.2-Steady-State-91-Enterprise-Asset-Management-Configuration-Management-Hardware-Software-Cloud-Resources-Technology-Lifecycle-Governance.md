# 1. Purpose

This document establishes the ninety-first document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-90 – Enterprise Procurement Governance, Sourcing, Supplier Selection, Third-Party Management & Procurement Assurance.

The purpose is to establish the permanent enterprise operating model for asset governance, asset ownership, asset inventory, configuration management, configuration items, hardware lifecycle, software lifecycle, cloud resource management, technology discovery, inventory reconciliation, ownership, licensing, entitlement, asset classification, asset risk, lifecycle planning, acquisition coordination, deployment, operation, maintenance, refresh, replacement, retirement, secure disposal, configuration assurance, asset financial management, asset compliance, asset records, asset relationships, dependency mapping, baseline management, configuration drift, asset exceptions, remediation, asset assurance, asset metrics, dashboards, maturity and continual enterprise asset management improvement.

The central objective is:

> **MFM must maintain accurate, authoritative and lifecycle-controlled knowledge of enterprise technology assets and configurations so that technology remains secure, compliant, supportable, financially controlled and aligned with business requirements.**

# 105. Definition of Ready

An asset, configuration item, lifecycle action, software license review, cloud resource, retirement, disposal, exception, remediation or assurance review is Ready when identity, owner, scope, criticality, dependencies, lifecycle state, requirements, decision authority, acceptance criteria and evidence requirements are defined.

# 106. Definition of Done

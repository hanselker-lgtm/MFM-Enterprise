# 1. Purpose

The purpose of the MFM Enterprise Architecture Intelligence Platform Architecture Framework is to establish a comprehensive platform architecture for enabling Enterprise Intelligence capabilities.

The Intelligence Platform Architecture Framework shall provide:

- intelligence platform principles
- platform governance
- infrastructure architecture
- computing architecture
- intelligence data platform architecture
- intelligence model platform architecture
- integration platform architecture
- application platform architecture
- runtime architecture
- deployment architecture
- platform monitoring
- platform performance
- platform evolution

The framework ensures that Enterprise Intelligence capabilities are supported by scalable, secure and reliable platform foundations.

---

# 2. Scope

The Intelligence Platform Architecture Framework covers all MFM Enterprise Architecture platform domains:

- Enterprise Intelligence Platform Model
- Platform Governance
- Infrastructure Architecture
- Computing Architecture
- Data Platform Architecture
- Model Platform Architecture
- Integration Platform Architecture
- Application Platform Architecture
- Runtime Architecture
- Deployment Architecture
- Platform Monitoring
- Platform Performance
- Platform Maturity
- Platform Roadmaps
- Platform Evolution

The framework applies to:

- intelligent organisations
- AI-enabled enterprises
- intelligence ecosystems
- intelligent operating environments
- future adaptive enterprises

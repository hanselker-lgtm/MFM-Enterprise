# 1. Purpose

This document establishes the one-hundred-and-twenty-sixth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-125 – Enterprise Infrastructure Architecture, Infrastructure Operations, Compute, Storage, Virtualization, Operating Systems, Infrastructure Security, Infrastructure Resilience & Infrastructure Assurance.

The purpose is to establish the permanent enterprise operating model for network strategy, network governance, network architecture, LAN/WAN, routing, switching, wireless, internet connectivity, remote access, DNS, DHCP, load balancing, network segmentation, network security, network monitoring, network performance, network capacity, network incidents, network changes, network lifecycle, network suppliers, network compliance, network exceptions, remediation, network resilience, network assurance, metrics, dashboards, maturity and continual enterprise network capability improvement.

The central objective is:

> **MFM must govern network capability as a controlled enterprise foundation, ensuring that connectivity between users, applications, data, infrastructure, cloud services, external parties and business locations is secure, reliable, observable, resilient, scalable and lifecycle-controlled.**

# 124. Final Network Governance Principle

> **MFM must govern network capability as a controlled enterprise foundation, ensuring that connectivity between users, applications, data, infrastructure, cloud services, external parties and business locations is secure, reliable, observable, resilient, scalable and lifecycle-controlled.**

# 125. Final Connectivity Principle

> **Network connectivity must have clearly defined purpose, ownership, security, capacity, availability, performance and recovery characteristics.**

# 126. Final Segmentation Principle

> **Network segmentation must reflect trust, sensitivity, function, criticality and threat exposure and must prevent unnecessary lateral movement.**

# 127. Final Routing Principle

> **Routing must be controlled, documented, appropriately redundant, secure and observable.**

# 128. Final Wireless Principle

> **Wireless services must provide appropriate coverage, capacity, authentication, encryption, segmentation, monitoring and lifecycle governance.**

# 129. Final Remote Access Principle

> **Remote access must be explicitly authorized, strongly authenticated where required, appropriately secured, monitored and lifecycle-controlled.**

# 130. Final Network Security Principle

> **Network security must integrate segmentation, firewalls, access control, encryption, secure management, monitoring, threat detection and vulnerability management.**

# 131. Final Resilience Principle

> **Critical network services must address link, device, provider, power, routing and service failures through appropriate redundancy and tested recovery.**

# 132. Final Lifecycle Principle

> **Network infrastructure must be actively managed from procurement and deployment through support, maintenance, modernization, replacement and secure retirement.**

# 133. Final Assurance Principle

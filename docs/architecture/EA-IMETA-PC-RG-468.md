# 2. Purpose

EA-IMETA-PC-RG-468 establishes the executive portfolio-control layer above the resilience investment optimisation architecture defined by RG-467.

RG-467 governs investment across scenarios, capability gaps, time horizons and strategic options.

RG-468 connects that resilience investment system to enterprise-level capital allocation, executive priorities, competing strategic demands, option management and long-horizon value creation.

The architecture SHALL answer:

> **How does the enterprise ensure that resilience investment competes transparently and intelligently for capital, management attention and organisational capacity while protecting critical capabilities, preserving strategic options and maintaining executive visibility of long-term value, risk and adaptability?**

The architecture SHALL distinguish:

```text
STRATEGIC RESILIENCE PORTFOLIO
= GOVERNED SET OF RESILIENCE INVESTMENTS MANAGED AS PART OF ENTERPRISE STRATEGY

ENTERPRISE CAPITAL ALLOCATION
= GOVERNED DISTRIBUTION OF FINANCIAL AND NON-FINANCIAL CAPITAL ACROSS ENTERPRISE PRIORITIES

CAPITAL ENVELOPE
= TOTAL PRACTICAL RESOURCE CAPACITY AVAILABLE FOR ALLOCATION

RESILIENCE CAPITAL
= CAPITAL COMMITTED TO PROTECT OR DEVELOP RESILIENCE CAPABILITY

STRATEGIC CAPITAL
= CAPITAL COMMITTED TO LONG-TERM ENTERPRISE OBJECTIVES

CROSS-HORIZON ALLOCATION
= ALLOCATION ACROSS CURRENT, NEAR-TERM, MEDIUM-TERM AND LONG-TERM NEEDS

EXECUTIVE VALUE
= COMBINED VALUE OF FINANCIAL, OPERATIONAL, RESILIENCE, STRATEGIC AND OPTION OUTCOMES

VALUE DRIVER
= FACTOR THAT materially contributes to enterprise value

VALUE AT RISK
= VALUE EXPOSED TO A MATERIAL THREAT OR FAILURE

RESILIENCE VALUE
= VALUE CREATED BY REDUCING DISRUPTION EXPOSURE OR INCREASING ADAPTIVE CAPACITY

PORTFOLIO PRIORITY
= GOVERNED RELATIVE IMPORTANCE OF AN INVESTMENT OR CAPABILITY

CAPITAL COMPETITION
= CONDITION WHERE MULTIPLE PRIORITIES COMPETE FOR LIMITED RESOURCES

CAPITAL CONFLICT
= CONDITION WHERE ALLOCATION TO ONE OBJECTIVE materially reduces ability to achieve another

STRATEGIC TRADE-OFF
= EXPLICIT CHOICE BETWEEN COMPETING VALUE, risk, time or capability outcomes

EXECUTIVE DECISION
= DECISION RESERVED FOR DEFINED EXECUTIVE AUTHORITY

EXECUTIVE ESCALATION
= MOVEMENT OF A PORTFOLIO ISSUE TO THE AUTHORITY LEVEL REQUIRED TO RESOLVE IT

PORTFOLIO STEWARDSHIP
= ONGOING GOVERNANCE OF PORTFOLIO VALUE, risk, capacity and strategic alignment

VALUE REALISATION
= CONFIRMED DELIVERY OF EXPECTED ENTERPRISE VALUE

VALUE LEAKAGE
= VALUE LOST BETWEEN APPROVAL, implementation and realised outcome

VALUE DECAY
= REDUCTION IN BENEFIT OVER TIME

VALUE CANNIBALISATION
= CONDITION WHERE ONE INITIATIVE REDUCES THE VALUE OF ANOTHER

PORTFOLIO SYNERGY
= ADDITIONAL VALUE CREATED BY COORDINATED INVESTMENTS

PORTFOLIO CONFLICT
= CONDITION WHERE INVESTMENTS INTERFERE WITH ONE ANOTHER

CAPITAL VELOCITY
= RATE AT WHICH ALLOCATED CAPITAL IS CONVERTED INTO EFFECTIVE CAPABILITY OR VALUE

CAPITAL PRODUCTIVITY
= VALUE CREATED RELATIVE TO CAPITAL CONSUMED

MANAGEMENT ATTENTION
= LIMITED EXECUTIVE AND LEADERSHIP CAPACITY AVAILABLE FOR GOVERNANCE AND CHANGE

ATTENTION CAPACITY
= PRACTICAL LIMIT OF SIMULTANEOUS EXECUTIVE PRIORITIES

STRATEGIC OVERLOAD
= CONDITION WHERE PRIORITY DEMAND EXCEEDS DECISION OR EXECUTION CAPACITY

PORTFOLIO LOAD
= TOTAL DEMAND CREATED BY ACTIVE initiatives

PORTFOLIO FRICTION
= LOSS OF VALUE CAUSED BY coordination, dependency or governance complexity

OPTION PORTFOLIO
= GOVERNED COLLECTION OF FUTURE strategic options

OPTION MATURITY
= DEGREE TO WHICH AN OPTION CAN BE ACTIVATED EFFECTIVELY

OPTION READINESS
= DEGREE TO WHICH an option can be converted into action within required time

OPTION COST
= RESOURCE REQUIRED TO MAINTAIN AN OPTION

OPTION EXPIRY
= POINT AFTER WHICH AN OPTION NO LONGER HAS SUFFICIENT VALUE OR FEASIBILITY

OPTION ACTIVATION
= GOVERNED conversion of a preserved option into an active strategic response

OPTION DEACTIVATION
= CONTROLLED retirement of an option

CAPITAL GATE
= GOVERNED POINT AT WHICH CAPITAL COMMITMENT IS APPROVED, RELEASED OR REASSESSED

STRATEGIC GATE
= GOVERNED POINT AT WHICH strategic alignment is reviewed

PORTFOLIO GATE
= GOVERNED POINT AT WHICH overall portfolio balance is reviewed

REBALANCING TRIGGER
= CONDITION REQUIRING PORTFOLIO REALLOCATION OR REVIEW

VALUE THRESHOLD
= MINIMUM EXPECTED OR OBSERVED VALUE REQUIRED FOR CONTINUATION

RESILIENCE FLOOR
= MINIMUM ACCEPTABLE RESILIENCE CAPABILITY THAT SHALL NOT BE UNDERFUNDED

STRATEGIC RESERVE
= CAPITAL OR CAPACITY HELD TO PRESERVE RESPONSE AND FUTURE CHOICE

LIQUIDITY OF OPTION
= ABILITY TO ACTIVATE AN OPTION WITHOUT MATERIAL DELAY

ADAPTATION BUDGET
= RESOURCES RESERVED FOR FUTURE CHANGE AND UNCERTAINTY

TRANSFORMATION CAPACITY
= ORGANISATIONAL ABILITY TO IMPLEMENT LARGE-SCALE CHANGE

PORTFOLIO RESILIENCE
= ABILITY OF THE TOTAL STRATEGIC PORTFOLIO TO CONTINUE CREATING VALUE UNDER MULTIPLE CONDITIONS

EXECUTIVE VALUE GOVERNANCE
= GOVERNED SYSTEM FOR BALANCING VALUE, risk, resilience, capital, options and strategic objectives

STRATEGIC LEARNING
= CONVERSION OF PORTFOLIO OUTCOMES INTO IMPROVED ENTERPRISE STRATEGY

CAPITAL LEARNING LOOP
= CYCLE FROM ALLOCATION TO OUTCOME, learning and future allocation

LONG-HORIZON VALUE
= VALUE CREATED OR PROTECTED OVER EXTENDED TIME HORIZONS

INTERGENERATIONAL CAPABILITY
= CAPABILITY THAT PRESERVES FUTURE ENTERPRISE CHOICES AND resilience beyond the immediate planning horizon
```

# 3. Core Principle

> **Enterprise resilience SHALL be governed as a strategic value portfolio, not as isolated defensive expenditure; capital, attention, capability, optionality and reserves SHALL therefore be allocated across horizons according to exposure, strategic value, resilience floors, uncertainty and future choice.**

```text

   ↓

   ↓

   ↓

   ↓

   ↓
LEARNING
   ↓

   ↺
```

# 1. Purpose

This document establishes the seventy-first document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-70 – Enterprise Supplier, Vendor, Contract, Third-Party, Outsourcing & Supplier Performance Management.

The purpose is to establish the permanent enterprise operating model for project management, programme management, portfolio management, PMO governance, project intake, prioritization, business cases, delivery governance, project planning, scope management, requirements, dependencies, milestones, resources, financial control, project risk, project issues, project decisions, project changes, quality, delivery assurance, benefits management, benefits realization, stakeholder management, communication, project reporting, project closure, lessons learned, change portfolio management, transformation coordination, delivery maturity and continual project and portfolio improvement.

The central objective is:

> **MFM must select, govern and deliver projects, programmes and portfolios in a controlled manner so that organizational change and investment produce measurable strategic, operational, financial, regulatory, resilience or capability outcomes.**

# 3. Project Management Objective

The primary objective is:

> **Deliver approved project outcomes within agreed scope, time, cost, quality, risk and governance parameters.**

# 4. Programme Management Objective

The primary objective is:

> **Coordinate related projects and workstreams to achieve outcomes that cannot be achieved effectively through individual projects alone.**

# 5. Portfolio Management Objective

The primary objective is:

> **Select and balance investments and change initiatives according to strategic value, risk, capacity, dependencies and available resources.**

# 6. PMO Objective

The primary objective is:

> **Provide consistent governance, standards, visibility, assurance and decision support across projects, programmes and portfolios.**

# 7. Benefits Objective

The primary objective is:

> **Ensure approved investments produce measurable and owned benefits.**

# 8. Change Portfolio Objective

The primary objective is:

> **Coordinate organizational change so that concurrent initiatives remain manageable, prioritized and aligned with organizational capacity.**

# 98. Definition of Ready

A project, programme, portfolio initiative, business case, change request, milestone, deliverable, risk, issue, dependency, benefit, assurance review or remediation item is Ready when purpose, owner, scope, expected outcome, dependencies, resources, financial requirements, risk, governance, acceptance criteria and evidence requirements are defined.

# 99. Definition of Done

A project or portfolio work item is Done when:

```text
Requirement Identified
        ↓
Owner Assigned
        ↓
Work Completed
        ↓
Acceptance Criteria Met
        ↓
Quality / Risk / Financial Validation Completed where Required
        ↓
Documentation Updated
        ↓
Operational Transition Completed where Required
        ↓
Benefits Ownership Established
        ↓
Evidence Captured
        ↓
Findings / Exceptions Addressed
        ↓
Outcome Accepted
```

# 1. Purpose

The purpose of the MFM Enterprise Architecture Data Reference Model is to establish a consolidated reference model describing Enterprise Data capabilities across the complete MFM Enterprise Architecture Framework from EA-000 through EA-599.

The Data Reference Model shall provide:

- data identification
- data classification
- data ownership
- data relationships
- data information mapping
- data application mapping
- data lifecycle management
- data governance
- architecture traceability

The model shall establish a common Enterprise language for defining, managing and evolving data assets.

---

# 2. Scope

The Data Reference Model covers all MFM Enterprise Architecture data domains:

- Architecture Data
- Business Data
- Operational Data
- Transaction Data
- Master Data
- Reference Data
- Analytical Data
- Metadata
- Security Data
- Governance Data
- Ecosystem Data
- Evolution Data

The model applies to:

- strategic data
- operational data
- analytical data
- transactional data
- master data
- reference data
- knowledge-related data
- transformation data
- evolution data

---

# 3. Enterprise Data Architecture Principles

The Data Reference Model shall follow these principles.

---

## Data as an Enterprise Asset

Data shall be managed as a strategic Enterprise asset.

---

## Data Ownership

Every data asset shall have defined ownership and accountability.

---

## Data Governance

Data shall be managed according to Enterprise policies and standards.

---

## Data Quality

Data shall be accurate, complete, consistent and reliable.

---

## Data Security

Data shall be protected throughout its complete lifecycle.

---

## Data Traceability

Data origin, movement and usage shall be traceable.

---

## Data Accessibility

Authorized users and systems shall have appropriate access to required data.

---

## Continuous Data Evolution

Data capabilities shall continuously evolve according to Enterprise requirements.

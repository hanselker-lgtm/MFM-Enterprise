# 1. Purpose

The purpose of the MFM Enterprise Architecture Intelligence Analytics Operating Architecture Framework is to establish an operational analytics architecture that ensures Intelligence analytics are governed, managed, processed, validated, visualised and continuously improved.

The Intelligence Analytics Operating Architecture Framework shall provide:

- analytics operating principles
- analytics governance frameworks
- analytics lifecycle structures
- analytics management models
- analytics processing models
- analytics model structures
- analytics insight models
- analytics visualisation structures
- analytics validation models
- analytics security models
- analytics monitoring structures
- analytics automation models
- analytics evolution models
- maturity assessment
- operating model

The framework provides the foundation for reliable, trusted and continuously improving Intelligence analytics capabilities.

# 1. Purpose

This document establishes the one-hundred-and-forty-fifth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-144 – Enterprise Data Architecture & Data Management, Data Governance, Data Strategy, Data Classification, Data Ownership, Data Quality, Master Data, Metadata, Data Lineage, Data Integration, Data Security, Data Privacy, Data Retention, Data Lifecycle, Data Resilience, Data Recovery, Data Compliance & Data Assurance.

The purpose is to establish the permanent enterprise operating model for data-platform strategy, governance, architecture, data warehouses, data lakes, lakehouse capabilities, data pipelines, ETL/ELT, data processing, data transformation, analytics, business intelligence, reporting, dashboards, data science, analytical data quality, platform security, platform resilience, platform recovery, platform lifecycle, suppliers, compliance, exceptions, remediation, assurance, metrics, maturity and continual enterprise data-platform capability improvement.

The central objective is:

> **MFM must operate enterprise data and analytics platforms as governed, trusted, secure, scalable, observable, resilient and lifecycle-managed capabilities that transform enterprise data into reliable information, insight, reporting and analytical value.**

The primary objective is:

The primary objective is:

# 5. Analytics Objective

# 7. Platform Resilience Objective

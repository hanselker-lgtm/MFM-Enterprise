## Purpose
Establish the authoritative mandatory-regression-response-reassessment layer defining when and how the current response, classification, consequence, effectiveness determination and governed state shall be reassessed because evidence, conditions, assumptions, impact or response performance have changed.

## Core Principle
Reassessment is a controlled re-evaluation of the current governed state. It shall not merely repeat the original decision; it shall determine whether the assumptions, evidence, classification, consequence, response and effectiveness remain valid in light of new information or changed conditions.

```text
CURRENT REGRESSION STATE
      ↓
TRIGGER / NEW EVIDENCE / CHANGE
      ↓
REASSESS CURRENT CONDITIONS
      ↓
REVIEW EVIDENCE + ASSUMPTIONS + IMPACT
      ↓
RECLASSIFY / RECONSEQUENCE / REDIRECT RESPONSE
      ↓
REVALIDATE / REVERIFY
      ↓
CONTINUE / REOPEN / ESCALATE / RE-CLOSE
```

## Reassessment Quality Test
```text
VALID TRIGGER
+
CURRENT STATE
+
CURRENT EVIDENCE
+
CHANGED ASSUMPTIONS IDENTIFIED
+
IMPACT RE-EVALUATED
+
CLASSIFICATION REVIEWED
+
CONSEQUENCE REVIEWED
+
RESPONSE EFFECTIVENESS REVIEWED
+
AUTHORIZED DECISION
=
VALID GOVERNED REASSESSMENT
```

SECURITY, RESILIENCE, SAFETY AND COMPLIANCE REASSESSMENT SHALL RECEIVE APPROPRIATE RIGOR

REPEATED REASSESSMENT WITHOUT CONVERGENCE SHALL TRIGGER GOVERNANCE REVIEW

## Regression Response Reassessment Structure

| Element | Required definition |
|---|---|
| Trigger | Reason reassessment is required |
| Current State | State being reassessed |
| Evidence | Current supporting information |
| Assumptions | Conditions underlying decisions |
| Impact | Current and potential effect |
| Classification | Current regression meaning |
| Consequence | Required treatment |
| Response | Current action |
| Effectiveness | Current response result |
| Decision | Reassessment outcome |

## Regression Response Reassessment Objective

Determine whether the current response governance remains valid and whether classification, consequence, response, effectiveness or closure state must change.

## Regression Response Reassessment Definition

Reassessment is the controlled re-evaluation of an active regression and its governance decisions in response to material new evidence, changed conditions, failed assumptions, response ineffectiveness or other defined triggers.

## Regression Response Reassessment Scope

Scope shall include the affected condition, current response, dependencies, assumptions, evidence, impacts, residual risks and governance boundaries relevant to the trigger.

## Regression Response Reassessment Authority

Authority shall define who initiates, conducts, approves and challenges reassessment and who may require reopening or escalation.

## Regression Response Reassessment Criteria

Criteria shall define when reassessment is complete and what decisions must be revisited.

```text
TRIGGER
↓
CURRENT STATE REVIEW
↓
NEW EVIDENCE / CHANGED ASSUMPTIONS
↓
IMPACT REASSESSMENT
↓
DECISION VALID?
├── YES → CONTINUE
└── NO → RECLASSIFY / RECONSEQUENCE / CHANGE RESPONSE
```

## Regression Response Reassessment Triggers

Triggers include material new evidence, changed conditions, failed effectiveness, repeated regression, threshold breach, changed dependency, changed risk, invalid assumption, material scope expansion or governance concern.

## Regression Response Reassessment Inputs

Inputs shall include current observations, prior decisions, evidence, response results, effectiveness measures, residual risk, dependencies, change records and relevant historical events.

## Regression Response Reassessment Method

The method shall compare the current state with required state, reassess assumptions and determine whether existing classification, consequence and response remain valid.

```text
CURRENT STATE
↓
REQUIRED STATE
↓
DELTA + ASSUMPTIONS + EVIDENCE
↓
REASSESS DECISIONS
```

## Regression Response Reassessment Evidence

Evidence shall be current, attributable, traceable and sufficient to explain why the previous decision remains valid or why it must change.

## Regression Response Reassessment Decision

The outcome shall explicitly state whether to continue, change classification, change consequence, change response, reopen, escalate, revalidate or close.

```text
CONTINUE
CHANGE CLASSIFICATION
CHANGE CONSEQUENCE
CHANGE RESPONSE
REOPEN
ESCALATE
REVALIDATE
CLOSE / RE-CLOSE
```

## Regression Response Reassessment Accountability

The accountable role shall remain explicit for both the reassessment and resulting decision.

## Security Regression Response Reassessment

Reassess security exposure, threat conditions, controls, access, boundaries, incidents and response effectiveness when relevant.

## Resilience Regression Response Reassessment

Reassess availability, capacity, recovery, continuity, dependencies and operational resilience when conditions change.

## Compliance Regression Response Reassessment

Reassess applicable requirements, control status, evidence, exposure and any changed regulatory or contractual context.

## Data Regression Response Reassessment

Reassess data integrity, quality, lineage, access, retention, use and remediation effectiveness where relevant.

## AI and Agent Regression Response Reassessment

Reassess AI/agent authority, policies, tools, data, autonomy, behaviour and safety boundaries when evidence or operating conditions change.

```text
AI / AGENT STATE
↓
TRIGGER
↓
AUTHORITY / POLICY / TOOL / DATA / AUTONOMY / BEHAVIOUR REVIEW
↓
VALID?
├── YES → CONTINUE / REVALIDATE
└── NO → LIMIT / REOPEN / REMEDIATE / ESCALATE
```

## Regression Response Reassessment Failure

Failure to conduct required reassessment, inability to obtain evidence or inability to reach a valid decision shall itself be governed and may require escalation or protective action.

```text
REASSESSMENT FAILURE
↓
PROTECT REQUIRED STATE
↓
ESCALATE / RESTORE EVIDENCE
↓
REASSESS
```

## Regression Response Reassessment Escalation

Escalation shall occur when reassessment identifies material change beyond local authority, unresolved uncertainty with high potential impact, repeated failure or conflict between governance decisions.

## Regression Response Reassessment Review and Learning

Reviews shall identify recurring triggers, weak assumptions, ineffective decision criteria, delayed reassessment and opportunities to improve monitoring, detection, classification, consequence and response.

## Reassessment Anti-Gaming Control
Reassessment shall not be delayed, narrowed or avoided to preserve an earlier classification, consequence, effectiveness determination or closure. Current evidence and required state remain controlling.

Historical reassessments, triggers, evidence, prior decisions, changed assumptions and resulting decisions shall remain preserved according to applicable retention and governance requirements.

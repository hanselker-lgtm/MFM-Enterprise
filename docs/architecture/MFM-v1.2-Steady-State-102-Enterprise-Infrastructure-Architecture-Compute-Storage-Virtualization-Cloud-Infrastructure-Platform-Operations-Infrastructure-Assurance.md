# 1. Purpose

This document establishes the one-hundred-and-second document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-101 – Enterprise Network Architecture, Network Operations, Connectivity, Segmentation, DNS, IPAM, Remote Access & Network Assurance.

The purpose is to establish the permanent enterprise operating model for infrastructure architecture, compute platforms, servers, operating systems, virtualization, containers, storage, backup infrastructure, cloud infrastructure, infrastructure provisioning, infrastructure configuration, platform monitoring, infrastructure capacity, availability, resilience, patching, lifecycle management, infrastructure security, infrastructure incidents, infrastructure changes, infrastructure automation, infrastructure assurance, findings, exceptions, remediation, infrastructure metrics, dashboards, maturity and continual enterprise infrastructure capability improvement.

The central objective is:

> **MFM must provide secure, resilient, scalable, observable and maintainable infrastructure platforms that reliably host enterprise applications, services and data throughout their lifecycle.**

# 120. Definition of Ready

An infrastructure architecture, compute platform, storage service, virtualization platform, container platform, cloud resource, backup service, infrastructure change, capacity initiative, exception, remediation or assurance review is Ready when purpose, owner, workload, dependencies, security requirements, capacity requirements, availability requirements, recovery requirements, lifecycle, cost, change authority and acceptance criteria are defined.

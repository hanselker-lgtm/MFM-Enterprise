# 1. Purpose

The purpose of the MFM Enterprise Architecture Intelligence Operating Model Architecture Framework is to establish a unified operating model that defines how Intelligence capabilities are organised, governed, executed and continuously developed.

The Intelligence Operating Model Architecture Framework shall provide:

- operating model principles
- organisational structures
- capability models
- role models
- responsibility models
- process models
- decision models
- coordination models
- resource models
- competence models
- culture models
- performance models
- value models
- change models
- evolution models
- maturity assessment
- operating model framework

The framework provides the foundation for effective, coordinated and continuously improving Intelligence operations.

# 1. Purpose

This document establishes the one-hundred-and-twelfth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-111 – Enterprise Cloud Architecture, Cloud Governance, Cloud Security, Cloud Operations, Cloud Cost Management & Cloud Assurance.

The purpose is to establish the permanent enterprise operating model for application strategy, application architecture, application portfolio management, application ownership, application lifecycle, application environments, software delivery, APIs, integration, middleware, application security, secure development, application monitoring, application resilience, application backup and recovery, application incidents, application changes, technical debt, application suppliers, application compliance, application exceptions, application remediation, application assurance, application metrics, dashboards, maturity and continual enterprise application capability improvement.

The central objective is:

> **MFM must govern and operate enterprise applications as controlled business capabilities, ensuring that applications are fit for purpose, securely designed, appropriately owned, integrated, observable, resilient, maintainable, compliant and governed throughout their lifecycle.**

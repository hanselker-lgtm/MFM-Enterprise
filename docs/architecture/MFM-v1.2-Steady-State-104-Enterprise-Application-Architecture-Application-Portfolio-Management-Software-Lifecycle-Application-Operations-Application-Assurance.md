# 1. Purpose

This document establishes the one-hundred-and-fourth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-103 – Enterprise Cloud Architecture, Cloud Governance, Cloud Security, Cloud Operations, FinOps, Cloud Resilience & Cloud Assurance.

The purpose is to establish the permanent enterprise operating model for application architecture, application portfolio governance, application ownership, software lifecycle, application standards, application environments, application deployment, application configuration, application monitoring, application performance, application resilience, application security integration, application incidents, application changes, release management, application dependencies, technical debt, application lifecycle, application modernization, application exceptions, application remediation, application assurance, application metrics, dashboards, maturity and continual enterprise application capability improvement.

The central objective is:

> **MFM must manage enterprise applications as controlled business capabilities throughout their lifecycle, ensuring that applications remain fit for purpose, secure, supportable, resilient, maintainable, observable and aligned with enterprise architecture and business value.**

# 117. Definition of Ready

An application architecture, application portfolio decision, software change, release, deployment, integration, modernization initiative, technical debt item, exception, remediation or assurance review is Ready when purpose, owner, business value, scope, dependencies, security requirements, data requirements, operational requirements, lifecycle, risk, approval authority and acceptance criteria are defined.

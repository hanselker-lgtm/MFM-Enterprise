# 1. Purpose

The purpose of this standard is to establish the Enterprise Information Service Integration Management Services Architecture supporting centralized, secure, standardized and continuously governed integration between Enterprise information services, applications, data domains and technology capabilities across the MFM Enterprise Platform.

Enterprise Information Service Integration Management Services shall

- provide centralized integration management capabilities
- establish integration governance
- manage information service integrations
- support integration lifecycle management
- support integration pattern management
- support API integration management
- support event integration management
- support message integration management
- support data integration management
- support metadata integration management
- support master information integration
- support reference data integration
- improve integration reliability
- improve interoperability
- reduce operational risks
- support compliance requirements
- support audit requirements
- protect information integrity
- support lifecycle governance
- enable enterprise automation
- ensure integration traceability
- improve operational transparency
- support continuous improvement

Enterprise Information Service Integration Management Services shall provide trusted and reusable integration management capabilities throughout the Enterprise.

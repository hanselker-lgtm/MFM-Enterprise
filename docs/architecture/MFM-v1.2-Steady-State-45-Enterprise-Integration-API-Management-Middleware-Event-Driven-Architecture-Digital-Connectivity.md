# 1. Purpose

This document establishes the forty-fifth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-44 – Enterprise Application Management, Application Lifecycle, Software Engineering, DevSecOps, Release & Deployment Management.

The purpose of this document is to establish the permanent enterprise operating model for application integration, API management, middleware, integration platforms, event-driven architecture, messaging, data exchange, service connectivity, interface governance, integration security, integration monitoring, integration reliability, integration lifecycle management, external connectivity, partner integration, digital channels, integration testing, integration resilience and continual integration improvement.

The central objective is:

> **MFM must provide secure, reliable, governed and reusable integration capabilities that connect applications, data, services, users and external parties while maintaining traceability, resilience, performance and controlled change.**

# 1. Purpose

This document establishes the sixty-seventh document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-66 – Enterprise Application Management, Application Lifecycle, Software Delivery, DevSecOps, Testing, Release & Application Operations.

The purpose is to establish the permanent enterprise operating model for infrastructure management, infrastructure architecture alignment, compute, servers, virtualization, cloud infrastructure, network services, connectivity, network security coordination, platforms, operating systems, databases, middleware, storage, backup, recovery, endpoints, workplace technology, infrastructure monitoring, infrastructure logging, infrastructure performance, capacity, availability, patching, configuration, infrastructure security, infrastructure incidents, infrastructure problems, infrastructure changes, infrastructure releases, infrastructure continuity, disaster recovery, infrastructure lifecycle, infrastructure technical debt, infrastructure rationalization, infrastructure assurance, infrastructure findings, exceptions, remediation, infrastructure metrics, infrastructure dashboards, infrastructure maturity and continual infrastructure improvement.

The central objective is:

> **MFM must maintain secure, resilient, available, scalable, supportable and recoverable infrastructure that provides a dependable foundation for business services, applications, data and users.**

# 3. Infrastructure Management Objective

The primary objective is:

> **Ensure infrastructure remains secure, available, resilient, performant, supportable and aligned with business and service requirements.**

# 4. Compute Objective

The primary objective is:

> **Provide reliable and appropriately sized compute capacity for critical applications and services.**

# 5. Cloud Objective

The primary objective is:

> **Provide governed, secure, resilient and cost-aware cloud infrastructure and platform capabilities.**

# 6. Network Objective

The primary objective is:

> **Provide secure, resilient and reliable connectivity between users, services, applications, infrastructure and external dependencies.**

# 7. Storage Objective

The primary objective is:

> **Provide reliable, scalable and protected storage aligned with data, performance, availability and recovery requirements.**

# 8. Backup Objective

The primary objective is:

> **Protect critical systems and data through reliable, monitored and regularly tested backup and recovery capabilities.**

# 9. Endpoint Objective

The primary objective is:

> **Provide secure, managed and supportable endpoint capabilities for authorized users and operational needs.**

# 10. Infrastructure Operations Objective

The primary objective is:

> **Operate infrastructure in a controlled, monitored and continuously improving manner.**

# 107. Definition of Ready

An infrastructure component, cloud resource, network change, storage service, backup capability, endpoint, recovery capability, technical-debt item, exception or remediation item is Ready when scope, owner, dependency, capacity, security, availability, recovery, lifecycle, acceptance criteria and evidence requirements are defined.

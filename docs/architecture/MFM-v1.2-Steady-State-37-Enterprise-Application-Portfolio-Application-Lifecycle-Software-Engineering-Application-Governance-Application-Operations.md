# 1. Purpose

This document establishes the thirty-seventh document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-36 – Enterprise Human Resources, Workforce Management, Organizational Capability, Learning, Competence & People Governance.

The purpose of this document is to establish the permanent enterprise operating model for application governance, application portfolio management, software lifecycle management, application architecture, software engineering, development standards, source-code management, testing, release management, application operations, application support, technical debt, application security, application resilience, application data, integrations, application performance, application monitoring, application incidents, application continuity and continual application improvement.

The central objective is:

> **MFM applications must be governed, designed, developed, operated, secured, maintained and retired as controlled enterprise assets throughout their lifecycle, with clear ownership, reliable service, appropriate security, sustainable architecture and measurable business value.**

# 136. Definition of Ready

An application, software or application-operations work item is Ready when:

- The application, requirement, feature, defect, release, incident, problem, vulnerability, technical-debt item, integration, lifecycle event, finding, exception or retirement activity is clearly identified.
- Ownership, scope, criticality, architecture, security, privacy, data, operational, continuity, financial and supplier requirements are known.
- Development, testing, deployment, monitoring, evidence, approval and acceptance requirements are defined.

# 1. Purpose

The purpose of the MFM Enterprise Architecture Intelligence Data Operating Architecture Framework is to establish an operational data architecture that ensures Intelligence data is governed, managed, processed, protected, monitored and continuously improved.

The Intelligence Data Operating Architecture Framework shall provide:

- data operating principles
- data governance frameworks
- data lifecycle structures
- data management models
- data quality frameworks
- data integration structures
- data processing models
- data security models
- data monitoring structures
- data automation models
- data evolution models
- maturity assessment
- operating model

The framework provides the foundation for reliable, trusted and continuously improving Intelligence data capabilities.

---

- all future Intelligence data development

The Intelligence Data Operating Architecture Framework shall follow these principles.

## Principle 3 – Data Quality

---

## Principle 4 – Data Security

Data shall be protected throughout its lifecycle.

## Principle 5 – Data Availability

## Purpose

Establish the authoritative mandatory procedural verification layer for RG-271, determining whether the substantive validation of RG-270 verification was correctly performed, evidenced, authorized, decided, recorded and implemented.

## Core Principle

RG-270 determines whether the RG-269 verification is substantively effective. RG-271 verifies that RG-270's validation of that verification was correctly performed and implemented.

```text
RG-268 → VALIDATE
RG-269 → VERIFY
RG-270 → VALIDATE
RG-271 → VERIFY
```

```text
RG-270 SUBSTANTIVE VALIDATION
        ↓
RG-271 PROCEDURAL VERIFICATION
        ↓
WAS RG-270 CORRECTLY PERFORMED?
```

A positive RG-270 validation SHALL NOT automatically prove that RG-270 was correctly verified.

# 1. Purpose

This document establishes the thirty-eighth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-37 – Enterprise Application Portfolio, Application Lifecycle, Software Engineering, Application Governance & Application Operations.

The purpose of this document is to establish the permanent enterprise operating model for technology infrastructure, cloud services, network services, end-user computing, compute platforms, storage, virtualization, operating systems, databases, infrastructure platforms, infrastructure monitoring, infrastructure security, capacity, availability, configuration, patching, backup, recovery, disaster recovery, infrastructure continuity, facilities dependencies, infrastructure suppliers and continual infrastructure improvement.

The central objective is:

> **MFM technology infrastructure must provide secure, resilient, scalable, supportable and cost-effective foundational services that enable applications, data, users and business services to operate reliably throughout their lifecycle.**

# 128. Definition of Ready

An infrastructure, cloud, network, endpoint, platform or operations work item is Ready when:

- The infrastructure service, asset, requirement, change, incident, problem, vulnerability, patch, recovery activity, finding, exception or retirement activity is clearly identified.
- Ownership, criticality, architecture, security, capacity, availability, continuity, data, financial, supplier and operational requirements are known.
- Provisioning, implementation, testing, monitoring, evidence, approval and acceptance requirements are defined.

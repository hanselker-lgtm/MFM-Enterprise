# 1. Purpose

This document establishes the one-hundred-and-first document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-100 – Enterprise Identity & Access Management, Privileged Access, Authentication, Authorization, Access Governance & Identity Assurance.

The purpose is to establish the permanent enterprise operating model for network architecture, network governance, connectivity, LAN/WAN, Internet connectivity, wireless, DNS, DHCP, IP address management, network segmentation, routing, switching, firewalls, remote access, VPN, network monitoring, network performance, network resilience, network configuration, network changes, network security integration, network incidents, network capacity, network assurance, findings, exceptions, remediation, network metrics, dashboards, maturity and continual enterprise network capability improvement.

The central objective is:

> **MFM must provide secure, resilient, observable and maintainable network connectivity that supports enterprise applications, identities, data, services and operations while controlling exposure and enabling effective network assurance.**

# 112. Definition of Ready

A network architecture, connectivity service, segmentation change, firewall rule, remote access service, network change, incident, capacity initiative, exception, remediation or assurance review is Ready when purpose, owner, scope, dependencies, risk, security requirements, availability requirements, performance requirements, change authority and acceptance criteria are defined.

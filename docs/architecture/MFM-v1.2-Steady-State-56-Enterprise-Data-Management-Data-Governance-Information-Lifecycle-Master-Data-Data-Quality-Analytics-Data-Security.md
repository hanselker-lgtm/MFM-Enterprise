# 1. Purpose

This document establishes the fifty-sixth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-55 – Enterprise Cybersecurity, Security Operations, Identity, Access, Threat, Vulnerability & Security Assurance.

The purpose is to establish the permanent enterprise operating model for data management, data governance, information governance, data ownership, data stewardship, information lifecycle, data architecture, metadata management, master data, reference data, data quality, data classification, data security, data privacy integration, data retention, data disposal, data lineage, data integration, data exchange, data platforms, reporting, analytics, business intelligence, data products, data controls, data standards, data assurance, data metrics, data maturity and continual data improvement.

The central objective is:

> **MFM must manage data and information as governed enterprise assets throughout their lifecycle, ensuring that data is trusted, owned, secure, appropriately classified, traceable, fit for purpose and available to authorized users and services.**

# 3. Data Management Objective

The primary objective is:

> **Manage enterprise data as a trusted, controlled and reusable asset that supports business operations, services, decisions and compliance.**

# 4. Data Governance Objective

The primary objective is:

> **Establish clear ownership, accountability, standards, decision rights and controls for enterprise data.**

# 5. Information Lifecycle Objective

The primary objective is:

> **Manage information from creation through use, storage, retention, archival and secure disposal according to business, legal, regulatory, security and privacy requirements.**

# 6. Data Quality Objective

The primary objective is:

> **Ensure that critical data is sufficiently accurate, complete, timely, consistent, valid, unique and fit for purpose.**

# 7. Analytics Objective

The primary objective is:

> **Provide trusted and appropriately governed data for reporting, analytics, decision support and data products.**

# 8. Data Security Objective

The primary objective is:

> **Protect data against unauthorized access, disclosure, alteration, destruction and inappropriate use.**

# 92. Definition of Ready

A data domain, dataset, data product, data-quality rule, integration, report, dashboard, analytics activity, security control, retention activity, finding, exception or improvement item is Ready when ownership, purpose, scope, classification, dependencies, quality requirements, security, privacy, lifecycle and acceptance criteria are defined.

# 94. Final Data Principle

> **MFM data must be treated as a governed enterprise asset that is trusted, owned, protected, traceable and fit for purpose.**

# 95. Final Governance Principle

> **Every material data domain must have clear ownership, stewardship, definitions, standards, controls and decision rights.**

# 96. Final Quality Principle

> **Critical data must meet defined quality requirements and material quality problems must be corrected at source where practical.**

# 97. Final Lifecycle Principle

> **Information must be managed from creation through use, retention, archival and secure disposal according to applicable requirements.**

# 98. Final Security Principle

> **Data access must be authorized, least-privileged, protected, monitored and periodically reviewed.**

# 99. Final Lineage Principle

> **Material data used for critical decisions, reporting or compliance must be sufficiently traceable to its source and transformations.**

# 100. Final Analytics Principle

> **Analytics and reporting must use trusted, defined and appropriately governed data.**

# 101. Final Assurance Principle

> **Material data-management controls must be supported by reliable evidence and periodically assessed for effectiveness.**

# 102. Final Improvement Principle

> **Data-quality issues, findings, usage patterns, incidents and lessons learned must continuously improve MFM data capability.**

# 103. Final Integration Principle

> **Data Management must integrate with Enterprise Architecture, Application Management, Infrastructure, Service Management, Cybersecurity, Privacy, Risk, Compliance, Business Continuity, Disaster Recovery, Suppliers, Finance, People and Project Management.**

# 104. Final Steady-State Data Principle

> **MFM must manage data and information as governed enterprise assets throughout their lifecycle, ensuring that data is trusted, owned, secure, appropriately classified, traceable, fit for purpose and available to authorized users and services.**

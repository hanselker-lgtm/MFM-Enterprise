# 1. Purpose

The purpose of the MFM Enterprise Architecture Intelligence Self-Mutualising Enterprise Architecture Framework is to establish a self-mutualising enterprise architecture model where intelligence, knowledge, learning, governance and enterprise capabilities continuously create mutual value, shared learning and collective optimisation.

- self-mutualising intelligence architecture

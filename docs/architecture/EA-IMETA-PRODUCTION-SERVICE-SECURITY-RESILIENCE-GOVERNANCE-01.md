# 1. PURPOSE

EA-IMETA-PRODUCTION-SERVICE-SECURITY-RESILIENCE-GOVERNANCE-01 establishes the governance layer above Security Resilience Adaptive.

It defines who owns, governs, approves, operates, assures, audits and improves the integrated capability.

The governance chain is:

```text
SECURITY
+
RESILIENCE
+
ADAPTATION
        ↓
GOVERNANCE
        ↓
AUTHORITY
        ↓
DECISION
        ↓
CONTROL
        ↓
ASSURANCE
        ↓
AUDIT
```

---

# 2. GOVERNANCE PRINCIPLE

> EA-IMETA SHALL GOVERN SECURITY, RESILIENCE AND ADAPTATION THROUGH EXPLICIT ACCOUNTABILITY, DEFINED DECISION RIGHTS, RISK-BASED AUTHORITY, CONTROLLED EXCEPTIONS, INDEPENDENT ASSURANCE AND AUDITABLE OUTCOMES.

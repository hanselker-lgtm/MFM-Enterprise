# 1. Purpose

This document establishes the seventy-sixth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-75 – Enterprise Application Portfolio, Application Lifecycle, Software Architecture, Application Operations & Application Service Management.

The purpose is to establish the permanent enterprise operating model for infrastructure portfolio management, compute, servers, operating systems, virtualization, network services, connectivity, cloud platforms, cloud infrastructure, storage, databases, middleware, platform services, infrastructure operations, infrastructure support, infrastructure availability, infrastructure performance, infrastructure capacity, infrastructure resilience, infrastructure security coordination, infrastructure monitoring, infrastructure logging, infrastructure incidents, infrastructure problems, infrastructure changes, infrastructure releases, infrastructure configuration, infrastructure patching, infrastructure backup, infrastructure recovery, infrastructure lifecycle, infrastructure modernization, infrastructure rationalization, infrastructure retirement, infrastructure financial management, infrastructure assurance, infrastructure findings, infrastructure exceptions, infrastructure remediation, infrastructure metrics, infrastructure dashboards, infrastructure maturity and continual infrastructure improvement.

The central objective is:

> **MFM must provide secure, reliable, resilient, scalable and cost-effective infrastructure and platform services that support business applications, data, users and critical business capabilities throughout their lifecycle.**

# 3. Infrastructure Management Objective

The primary objective is:

> **Ensure infrastructure remains secure, available, performant, resilient, supportable and aligned with business requirements.**

# 4. Compute Objective

The primary objective is:

> **Provide reliable compute capacity for applications and services according to demand, performance and resilience requirements.**

# 5. Network Objective

The primary objective is:

> **Provide secure, reliable and appropriately resilient connectivity between users, systems, services, locations and external networks.**

# 6. Cloud Objective

The primary objective is:

> **Provide governed, secure, scalable and economically controlled cloud infrastructure and platform capabilities.**

# 7. Storage Objective

The primary objective is:

> **Provide secure, reliable and appropriately performant storage capabilities aligned with data requirements and recovery objectives.**

# 8. Platform Objective

The primary objective is:

> **Provide standardized and supportable infrastructure platforms for applications, integration, data and business services.**

# 9. Infrastructure Operations Objective

The primary objective is:

> **Operate infrastructure services consistently through monitoring, support, incident, problem, change, capacity and recovery management.**

# 99. Definition of Ready

An infrastructure platform, change, release, modernization initiative, rationalization action, retirement, recovery procedure, incident, problem, capacity action, patching activity, assurance review or remediation item is Ready when purpose, owner, scope, service, dependencies, architecture, security, capacity, financial implications, recovery requirements, acceptance criteria and evidence requirements are defined.

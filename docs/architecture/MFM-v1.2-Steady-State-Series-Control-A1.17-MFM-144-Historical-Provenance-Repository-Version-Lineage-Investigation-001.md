# 10. Document-Generation Lineage

The current Series Control architecture itself was created because the original process could propagate:

```text
Document N
    ↓
Next Document N+1
    ↓
Next Document N+2
    ↓
...
```

without an intrinsic completion condition.

This means a historical `Next Document: 144` reference can have several meanings:

```text
planned generation
generated document
working-series artifact
completed document
later superseded document
```

The existence of the reference alone cannot distinguish these states.

This is precisely why A1.17 maintains a separate provenance state.

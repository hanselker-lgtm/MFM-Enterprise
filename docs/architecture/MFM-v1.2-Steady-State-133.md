# 1. Purpose

This document establishes the one-hundred-and-thirty-third document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-132 – Enterprise Cybersecurity Architecture, Security Governance, Security Operations, Security Monitoring, Threat Detection, Vulnerability Management, Security Incident Response, Security Engineering, Security Assurance & Cyber Resilience.

The purpose is to establish the permanent enterprise operating model for infrastructure strategy, infrastructure governance, infrastructure architecture, compute, storage, virtualization, operating systems, endpoint infrastructure, infrastructure operations, infrastructure monitoring, infrastructure capacity, infrastructure resilience, infrastructure security, infrastructure lifecycle, infrastructure suppliers, infrastructure compliance, infrastructure exceptions, remediation, infrastructure assurance, metrics, dashboards, maturity and continual enterprise infrastructure capability improvement.

The central objective is:

> **MFM must govern enterprise infrastructure as a controlled, secure, resilient and measurable foundation for business services, applications, data, identity, integration and operations, ensuring that infrastructure is appropriately designed, owned, monitored, protected, maintained, recovered, modernized and retired throughout its lifecycle.**

# 3. Infrastructure Governance Objective

The primary objective is:

> **Establish clear authority, ownership, architecture, standards, lifecycle controls, operational responsibilities, resilience requirements, security controls and assurance for enterprise infrastructure.**

# 4. Infrastructure Architecture Objective

The primary objective is:

> **Provide a coherent infrastructure foundation supporting business services, applications, data, identity, integration, security and operational requirements.**

# 5. Infrastructure Operations Objective

The primary objective is:

> **Operate infrastructure reliably through disciplined monitoring, maintenance, incident response, capacity management, configuration control, backup, recovery and continual improvement.**

# 6. Infrastructure Resilience Objective

The primary objective is:

> **Ensure critical infrastructure can withstand component, platform, site, supplier and technology failures and recover within defined service requirements.**

# 7. Infrastructure Capacity Objective

The primary objective is:

> **Ensure infrastructure capacity and performance remain sufficient for current and forecast business and service demand.**

# 8. Infrastructure Security Objective

The primary objective is:

> **Protect infrastructure against unauthorized access, exploitation, misconfiguration, malware, data loss and other threats through layered security controls.**

# 9. Infrastructure Assurance Objective

The primary objective is:

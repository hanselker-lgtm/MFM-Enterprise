# 1. Purpose

The purpose of this standard is to establish the Enterprise Information Service Ecosystem Optimization Services Architecture supporting secure, standardized and continuously governed optimization capabilities for improving ecosystem performance, efficiency, value creation and continuous improvement across the MFM Enterprise Platform.

Enterprise Information Service Ecosystem Optimization Services shall

- support ecosystem performance improvement

- support ecosystem process optimization
- support ecosystem resource optimization
- support ecosystem cost optimization
- support ecosystem value optimization
- support optimization analytics

- support optimization lifecycle management
- improve ecosystem efficiency
- improve ecosystem effectiveness
- improve ecosystem scalability
- improve ecosystem sustainability
- improve ecosystem value realization

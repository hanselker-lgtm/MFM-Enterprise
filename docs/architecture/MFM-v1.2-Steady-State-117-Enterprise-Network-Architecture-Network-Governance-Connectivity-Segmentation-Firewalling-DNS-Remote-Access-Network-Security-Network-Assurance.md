# 1. Purpose

This document establishes the one-hundred-and-seventeenth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-116 – Enterprise Identity & Access Management, IAM Governance, Authentication, Authorization, Privileged Access, Identity Lifecycle & IAM Assurance.

The purpose is to establish the permanent enterprise operating model for network strategy, network architecture, network governance, LAN/WAN, internet connectivity, wireless, remote access, VPN, network segmentation, firewalls, routing, switching, DNS, DHCP, IP address management, network monitoring, network performance, network resilience, network configuration, network incidents, network changes, network capacity, network suppliers, network security integration, network compliance, network exceptions, remediation, network assurance, network metrics, dashboards, maturity and continual enterprise network capability improvement.

The central objective is:

> **MFM must govern and operate network capabilities as secure, resilient and observable enterprise infrastructure, ensuring that connectivity, routing, segmentation, name resolution, remote access and network security support business services while controlling operational and cyber risk throughout the network lifecycle.**

# 3. Network Governance Objective

# 5. Connectivity Objective

The primary objective is:

# 7. Network Security Objective

# 8. Network Assurance Objective

# 106. Definition of Ready

A network architecture, connectivity service, segmentation design, firewall rule, DNS change, remote access arrangement, network change, recovery procedure, exception, remediation or assurance review is Ready when purpose, owner, scope, affected services, dependencies, security requirements, risk, approval authority and acceptance criteria are defined.

## Purpose
Establish the authoritative mandatory baseline-establishment layer that defines the verified reference state against which post-closure observations, deviations and potential regressions shall be measured.

## Core Principle
A post-closure baseline is not merely a snapshot. It is an authorized, evidence-backed and sufficiently characterized reference state that represents the conditions considered acceptable at the point of transition into post-closure monitoring.

```text
POST-CLOSURE STATE ACTIVE
      ↓
DEFINE BASELINE PURPOSE + SCOPE
      ↓
SELECT VALID REFERENCE STATE
      ↓
VERIFY BASELINE DATA / CONDITIONS
      ↓
AUTHORIZE BASELINE
      ↓
BASELINE ACTIVE
      ↓
COMPARE FUTURE OBSERVATIONS
      ↓
DETECT DEVIATION / REGRESSION
```

## Baseline Quality Test
```text
DEFINED REFERENCE PURPOSE
+
CORRECT SCOPE
+
VALID CURRENT STATE
+
SUFFICIENT OBSERVATIONS
+
KNOWN CONDITIONS / LIMITS
+
TRACEABLE EVIDENCE
+
AUTHORIZED ACCEPTANCE
+
VERSIONED BASELINE
=
VALID GOVERNED POST-CLOSURE BASELINE
```

## Baseline vs Snapshot
```text
SNAPSHOT
→ RECORDED STATE AT A POINT IN TIME

BASELINE
→ GOVERNED REFERENCE STATE USED FOR COMPARISON

REGRESSION
→ MATERIAL DEVIATION FROM THE GOVERNED REFERENCE STATE
```

## Baseline State Model
```text
BASELINE CANDIDATE
BASELINE UNDER VALIDATION
BASELINE ACCEPTED
BASELINE ACTIVE
BASELINE AMENDED
BASELINE SUPERSEDED
BASELINE INVALIDATED
BASELINE REJECTED
```

## Post-Closure Baseline Establishment Objective

Create a reliable reference state that enables meaningful detection of deviation, regression and loss of required post-closure conditions.

## Post-Closure Baseline Establishment Definition

Baseline establishment is the governed creation and acceptance of a verified reference state used for future comparison within post-closure monitoring.

## Post-Closure Baseline Establishment Scope

Scope shall identify systems, services, users, data, decisions, dependencies, environments, consumers, metrics and boundaries represented by the baseline.

## Post-Closure Baseline Establishment Authority

Authority shall define who may propose, validate, accept, amend, supersede or invalidate a baseline.

## Post-Closure Baseline Establishment Criteria

Criteria shall address validity, completeness, stability, representativeness, evidence quality, observation period and known limitations.

```text
CANDIDATE STATE
↓
VALID + STABLE + REPRESENTATIVE?
├── NO → REJECT / EXTEND OBSERVATION
└── YES
     ↓
EVIDENCE SUFFICIENT?
├── NO → GATHER EVIDENCE
└── YES → ACCEPT BASELINE
```

Preconditions include valid post-closure transition, stable governed state, defined scope, required observations, measurement definitions and acceptance authority.

## Post-Closure Baseline Establishment Evidence

Evidence shall preserve observations, measurement sources, timestamps, state descriptions, assumptions, validation results, acceptance and version history.

## Post-Closure Baseline Establishment Method

Methods may include verified snapshots, representative observation windows, multi-point measurement, controlled testing, sampling and independent validation.

Baseline establishment shall occur at an appropriate stable point after post-closure transition. Premature baselines may encode transient conditions and produce false regression signals.

## Baseline vs Snapshot

## Baseline Stability
A baseline shall not be established from a transient, degraded, unstable or otherwise unrepresentative state unless explicitly authorized and governed for that purpose.

## Baseline Representativeness
The baseline shall represent the intended operating conditions sufficiently to avoid systematically misclassifying normal variation as regression or regression as normal variation.

## Assumptions and Limitations
Material assumptions, dependencies, exclusions and measurement limitations shall be recorded as part of the baseline.

## Baseline Versioning
Every accepted baseline shall have a unique identity and version. Changes shall create traceable history rather than silently overwriting the previous reference state.

## Baseline Amendment
An amendment shall preserve why the baseline changed, who authorized the change, what evidence supported it and when the new version became effective.

## Baseline Invalidation
A baseline shall be invalidated where evidence shows that it no longer represents the governed reference state or was established using materially incorrect information.

## Baseline Without Full Observability
Where full observability is impossible, the baseline shall explicitly identify coverage gaps and define compensating controls rather than implying complete certainty.

## Baseline Anti-Gaming
Baseline establishment shall not be manipulated by selecting unusually favorable periods, excluding inconvenient measures or redefining normal conditions solely to suppress future regression detection.

## Relationship to Regression Detection
The baseline is the reference against which future observations are compared. It does not itself establish that a future deviation is material; classification and consequence governance remain separate.

```text
BASELINE
↓
FUTURE OBSERVATION
↓
COMPARE
↓
DEVIATION
↓
CLASSIFY
↓
REGRESSION DETERMINATION
```

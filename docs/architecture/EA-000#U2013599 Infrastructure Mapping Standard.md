# 1. Purpose

The purpose of the MFM Enterprise Architecture Infrastructure Reference Model is to establish a consolidated reference model describing Enterprise Infrastructure capabilities across the complete MFM Enterprise Architecture Framework from EA-000 through EA-599.

The Infrastructure Reference Model shall provide:

- infrastructure identification
- infrastructure classification
- infrastructure ownership
- infrastructure relationships
- infrastructure technology mapping
- infrastructure application mapping
- infrastructure lifecycle management
- architecture traceability

The model shall establish a common Enterprise language for defining, managing and evolving infrastructure capabilities.

---

# 2. Scope

The Infrastructure Reference Model covers all MFM Enterprise Architecture infrastructure domains:

- Architecture Infrastructure
- Business Infrastructure
- Information Infrastructure
- Data Infrastructure
- Application Infrastructure
- Integration Infrastructure
- Platform Infrastructure
- Compute Infrastructure
- Storage Infrastructure
- Network Infrastructure
- Security Infrastructure
- Cloud Infrastructure
- Ecosystem Infrastructure
- Evolution Infrastructure

The model applies to:

- strategic infrastructure
- operational infrastructure
- supporting infrastructure
- enabling infrastructure
- transformation infrastructure
- evolution infrastructure

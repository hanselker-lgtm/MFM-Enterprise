# 1. Purpose

This document establishes the sixty-fourth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-63 – Enterprise Cybersecurity, Information Security Operations, Identity, Access, Security Monitoring, Vulnerability & Security Incident Management.

The purpose is to establish the permanent enterprise operating model for enterprise architecture, business architecture alignment, information architecture, data architecture, application architecture, technology architecture, infrastructure architecture, integration architecture, security architecture coordination, cloud architecture, solution architecture, architecture principles, standards, reference architectures, technology standards, architecture decisions, architecture review, architecture governance, architecture compliance, technical debt, lifecycle management, technology rationalization, interoperability, integration patterns, architecture assurance, architecture findings, exceptions, remediation, architecture metrics, architecture dashboards, architecture maturity and continual architecture improvement.

The central objective is:

> **MFM must maintain a coherent, governed and sustainable architecture that aligns business capabilities, information, applications, technology, infrastructure and integrations with strategic objectives, security, resilience, service requirements and long-term maintainability.**

The purpose of the MFM Enterprise Architecture Intelligence Global Enterprise Architecture Framework is to establish a global enterprise architecture model that enables organisations, intelligent systems, autonomous agents and ecosystems to operate through globally connected intelligence capabilities, shared architecture principles and international collaboration.

The Intelligence Global Enterprise Architecture Framework shall provide:

- global enterprise reference model
- global capability architecture

- global interoperability architecture
- global maturity model
- global enterprise roadmap

The framework provides the foundation for a globally connected intelligent enterprise capability.

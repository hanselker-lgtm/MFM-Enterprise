# 1. PURPOSE

EA-IMETA-PRODUCTION-SERVICE-SECURITY-RESILIENCE-COMPLIANCE-CAPABILITY-01 establishes the controlled capability model for the production security-resilience compliance environment.

A capability represents an enduring organizational ability to produce a defined outcome under controlled conditions.

The capability lifecycle is:

```text
IDENTIFY
 ↓
DEFINE
 ↓
OWN
 ↓
MAP
 ↓
ASSESS
 ↓
OPERATE
 ↓
MEASURE
 ↓
ASSURE
 ↓
IMPROVE
 ↓
INVEST
 ↓
EVOLVE
```

---

# 2. CAPABILITY PRINCIPLE

> EA-IMETA SHALL MANAGE COMPLIANCE AS A SET OF OWNED, INTERDEPENDENT, MEASURABLE AND RESILIENT CAPABILITIES THAT CONTINUOUSLY PRODUCE REQUIRED COMPLIANCE OUTCOMES.

---

# 3. CAPABILITY VS PROCESS

A process describes how work is performed.

A capability describes the enduring ability to produce an outcome.

```text
PROCESS
→ HOW WORK IS DONE

CAPABILITY
→ WHAT THE ORGANIZATION MUST BE ABLE TO DO
```

---

# 4. CAPABILITY VS MATURITY

Maturity describes the quality and sophistication of a capability.

```text
CAPABILITY
+
MATURITY
=
CAPABILITY EFFECTIVENESS
```

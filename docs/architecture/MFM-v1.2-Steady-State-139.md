# 1. Purpose

This document establishes the one-hundred-and-thirty-ninth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-138 – Enterprise Identity & Access Management Architecture, Identity Governance, Authentication, Authorization, Privileged Access, Directory Services, Federation, SSO, MFA, Access Lifecycle, Identity Security, Access Reviews, Identity Monitoring, Identity Resilience, Identity Recovery & Identity Assurance.

The purpose is to establish the permanent enterprise operating model for integration strategy, integration governance, integration architecture, integration platforms, API management, messaging, event architecture, data integration, service integration, integration security, integration monitoring, integration performance, integration capacity, integration resilience, integration recovery, integration lifecycle, integration suppliers, integration compliance, integration exceptions, remediation, integration assurance, metrics, dashboards, maturity and continual enterprise integration capability improvement.

The central objective is:

> **MFM must govern enterprise integration as a controlled, secure, observable, resilient and lifecycle-managed capability that enables reliable interaction between applications, services, data platforms, users, cloud services, infrastructure and external parties.**

> **Provide coherent integration structures, patterns, interfaces, platforms and dependencies supporting business processes, applications, data, identity and enterprise services.**

The primary objective is:

# 2. Architectural Position

RG-483 is the third document in the new Enterprise Economics family.

RG-481 established economic decision-making and allocation economics.

RG-482 established resource intelligence, capacity forecasting, scarcity modelling, substitution and governed internal resource markets.

RG-483 now moves upward from **resources** to the **network of value created by those resources**.

The principal question becomes:

> **How does a change in one resource, capability, investment or portfolio propagate through dependent value streams, alter marginal value elsewhere, change portfolio trade-offs and ultimately affect enterprise-wide outcomes?**

The architecture therefore treats enterprise value as a connected network rather than a collection of independent business cases.

# 3. Core Principle

> **Enterprise value SHALL be understood as a network effect: resource changes, capability changes and portfolio decisions SHALL be evaluated for their direct, indirect, marginal, opportunity and dependency effects across the enterprise, while multi-objective optimisation SHALL remain constrained by strategy, resilience, security, governance and real-world capacity.**

```text
RESOURCE / CAPABILITY CHANGE
          ↓
DIRECT VALUE EFFECT
          ↓
DEPENDENCY PROPAGATION
          ↓
MARGINAL VALUE EFFECT
          ↓
PORTFOLIO INTERACTION
          ↓
ENTERPRISE TRADE-OFF
          ↓
MULTI-OBJECTIVE OPTIMISATION
          ↓
GOVERNED ALLOCATION
          ↓
VALUE REALISATION
          ↓
LEARNING
          ↺
```

# 182. Acceptance Criteria

EA-IMETA-PC-RG-483 is accepted when:

- material enterprise value networks can be represented;
- direct, second-order and material third-order effects can be analysed;
- marginal value and marginal risk are measurable;
- value thresholds, cliffs, flywheels and friction can be represented;
- portfolio dependencies, synergies and cannibalisation are visible;
- portfolio concentration, diversification and optionality are measurable;
- multi-objective optimisation is supported;
- objective weights and precedence are governed;
- Pareto frontiers and trade-off surfaces can be produced for material decisions;
- robust, stochastic and constrained optimisation are supported where appropriate;
- value attribution and realisation gaps are measurable;
- value models carry provenance, confidence and versioning;
- portfolio rebalancing considers current marginal value rather than sunk cost;
- counterfactual and scenario analysis are available;
- resource intelligence from RG-482 is integrated;
- security, resilience and transformation constraints remain authoritative;
- AI cannot redefine value, strategy or hard constraints;
- material optimisation remains explainable, auditable and appropriately human-governed;
- negative and scenario tests prevent unsafe portfolio optimisation.

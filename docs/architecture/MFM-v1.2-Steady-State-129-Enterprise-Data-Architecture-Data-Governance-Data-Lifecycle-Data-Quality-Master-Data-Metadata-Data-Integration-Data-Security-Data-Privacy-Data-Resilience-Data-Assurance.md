# 1. Purpose

This document establishes the one-hundred-and-twenty-ninth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-128 – Enterprise Application Architecture, Application Portfolio, Application Lifecycle, Application Integration, Application Security, Application Operations, Application Resilience & Application Assurance.

The purpose is to establish the permanent enterprise operating model for data strategy, data governance, data architecture, data ownership, data domains, data classification, data lifecycle, data quality, master data, reference data, metadata, data integration, data platforms, databases, analytics data, data security, data privacy, data retention, data backup, data recovery, data incidents, data changes, data suppliers, data compliance, data exceptions, remediation, data assurance, metrics, dashboards, maturity and continual enterprise data capability improvement.

The central objective is:

> **MFM must govern data as a controlled enterprise asset and capability, ensuring that data is appropriately owned, classified, architected, integrated, protected, governed for quality and privacy, retained and disposed of appropriately, resilient and recoverable, and used in alignment with business and service requirements.**

# 3. Data Governance Objective

The primary objective is:

> **Establish clear authority, ownership, standards, policies, lifecycle controls, security requirements, quality responsibilities, privacy requirements and assurance for enterprise data.**

# 4. Data Architecture Objective

The primary objective is:

> **Provide coherent data architectures supporting business capabilities, applications, integration, analytics, reporting, identity, infrastructure, cloud and operational requirements.**

# 5. Data Ownership Objective

The primary objective is:

> **Ensure material data has accountable ownership for purpose, quality, classification, access, lifecycle, security, privacy, retention and risk.**

# 6. Data Quality Objective

The primary objective is:

> **Ensure data is sufficiently accurate, complete, consistent, timely, valid, unique and fit for its intended business purpose.**

# 7. Data Security Objective

The primary objective is:

> **Protect data against unauthorized access, disclosure, alteration, destruction, loss and misuse throughout its lifecycle.**

# 8. Data Privacy Objective

The primary objective is:

> **Ensure personal and otherwise sensitive data is processed, protected, retained and disposed of in accordance with applicable requirements and defined business purposes.**

# 9. Data Resilience Objective

The primary objective is:

> **Ensure critical data remains available, protected, recoverable and usable within defined business and service requirements.**

# 10. Data Assurance Objective

The primary objective is:

> **Provide evidence that material data governance, architecture, quality, security, privacy, lifecycle, resilience and compliance controls operate effectively.**

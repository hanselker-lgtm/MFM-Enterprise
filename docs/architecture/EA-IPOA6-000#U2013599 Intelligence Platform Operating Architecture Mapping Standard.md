# 1. Purpose

The purpose of the MFM Enterprise Architecture Intelligence Platform Operating Architecture Framework is to establish an operational platform architecture that ensures Intelligence platforms can be established, operated, integrated, monitored, secured, scaled and continuously improved.

The Intelligence Platform Operating Architecture Framework shall provide:

- platform operating principles
- platform governance frameworks
- platform lifecycle models
- platform management models
- infrastructure models
- application platform models
- integration models
- data platform models
- model platform models
- security models
- monitoring models
- automation models
- scalability models
- resilience models
- improvement models
- evolution models
- maturity assessment
- operating model

The framework provides the foundation for stable, secure and continuously improving Intelligence platforms.

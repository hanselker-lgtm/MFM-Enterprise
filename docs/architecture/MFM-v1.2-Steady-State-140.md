# 1. Purpose

This document establishes the one-hundred-and-fortieth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-139 – Enterprise Integration Architecture & Integration Operations, Integration Governance, Integration Platforms, API Management, Messaging, Event Architecture, Data Integration, Service Integration, Integration Security, Integration Monitoring, Integration Resilience, Integration Capacity, Integration Lifecycle & Integration Assurance.

The purpose is to establish the permanent enterprise operating model for infrastructure strategy, infrastructure governance, infrastructure architecture, compute, storage, virtualization, data center services, cloud infrastructure, infrastructure security, infrastructure monitoring, infrastructure performance, infrastructure capacity, infrastructure resilience, infrastructure recovery, infrastructure lifecycle, infrastructure suppliers, infrastructure compliance, infrastructure exceptions, remediation, infrastructure assurance, metrics, dashboards, maturity and continual enterprise infrastructure capability improvement.

The central objective is:

> **MFM must govern enterprise infrastructure as a controlled, secure, resilient, observable, scalable and lifecycle-managed foundation that reliably supports business services, applications, data, identity, integration and enterprise operations.**

# 3. Infrastructure Governance Objective

The primary objective is:

> **Establish clear authority, ownership, architecture, standards, security requirements, operational responsibilities, lifecycle controls and assurance for enterprise infrastructure.**

# 4. Infrastructure Architecture Objective

The primary objective is:

> **Provide coherent compute, storage, virtualization, data center and cloud infrastructure foundations supporting enterprise applications, data, identity, integration and services.**

# 5. Infrastructure Operations Objective

The primary objective is:

> **Operate infrastructure reliably through disciplined monitoring, patching, configuration management, incident management, problem management, change management, capacity management and recovery.**

# 6. Infrastructure Security Objective

The primary objective is:

> **Protect infrastructure platforms, operating systems, workloads, configurations, credentials and administrative interfaces against unauthorized access, compromise and disruption.**

# 7. Infrastructure Resilience Objective

The primary objective is:

> **Ensure critical infrastructure can withstand component, platform, facility, network, cloud, supplier and operational failures and recover within defined service requirements.**

# 8. Infrastructure Assurance Objective

The primary objective is:

> **Provide reliable evidence that infrastructure architecture, security, operations, resilience, lifecycle and governance controls operate effectively.**

# 109. Final Improvement Principle

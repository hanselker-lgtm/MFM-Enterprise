# 9. Business Capability Architecture

The Business Capability Architecture Model defines how Enterprise capabilities are identified, structured, managed and evolved.

Business capabilities represent what the Enterprise is able to do in order to achieve strategic objectives and create value.

---

# 9.1 Business Capability Principles

Business capabilities shall ensure:

- strategic alignment
- clear ownership
- measurable value
- capability transparency
- continuous improvement

---

| Capability Ownership | Defines accountability |
| Capability Maturity | Measures capability development |
| Capability Dependencies | Defines relationships |

# 15. Business Value Stream Architecture

The Business Value Stream Architecture Model defines how Enterprise activities create value from stakeholder need to delivered outcome.

Value Streams provide an end-to-end view of value creation across the Enterprise.

---

# 15.1 Value Stream Principles

Value Streams shall ensure:

- stakeholder value focus
- end-to-end visibility
- business outcome alignment
- cross-functional collaboration
- continuous improvement

---

# 15.2 Value Stream Components

| Component | Description |
|---|---|
| Stakeholder Trigger | Defines initiating need |
| Value Stream Stages | Defines value creation steps |
| Capabilities | Enable value creation |
| Processes | Execute activities |
| Services | Deliver outcomes |
| Outcomes | Define achieved value |

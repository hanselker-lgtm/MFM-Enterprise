# 1. PURPOSE

Establish the authoritative control architecture for the portfolio operating model, defining control objectives, ownership, execution, evidence, monitoring, testing, exceptions, remediation, assurance, automation, performance, maturity and regression.

# 2. CONTROL PRINCIPLE

EA-IMETA SHALL OPERATE PORTFOLIO CONTROLS AS EXPLICIT, OWNED, TESTABLE AND EVIDENCE-BASED CONTROL OBJECTS THAT PROTECT STRATEGY, VALUE, RISK, CAPACITY, SECURITY, RESILIENCE, COMPLIANCE, DATA, AI/AGENTS AND BENEFIT REALIZATION.

# 3. CONTROL SCOPE

Controls apply to portfolio intake, planning, investment, prioritization, capacity, dependencies, risk, architecture, security, resilience, data, AI, agents, benefits, delivery coordination, reporting, decisions, change, exceptions, assurance, audit, continuity and closure.

# 4. CONTROL OBJECTIVE

Every material control shall establish what must be protected or achieved, who owns it, how it operates, what evidence is produced, how effectiveness is measured and what happens when it fails.

# 5. CONTROL LIFECYCLE

DESIGN → APPROVE → IMPLEMENT → EXECUTE → EVIDENCE → MONITOR → TEST → ASSURE → REMEDIATE → RETEST → IMPROVE → RETIRE.

# 6. CONTROL HIERARCHY

ENTERPRISE CONTROL → TRANSFORMATION CONTROL → PORTFOLIO CONTROL → OPERATING MODEL CONTROL → INITIATIVE CONTROL → TRANSACTION / EXECUTION CONTROL.

# 7. CONTROL OWNERSHIP

Each control shall have an accountable owner and, where appropriate, separate operator, reviewer, approver and assurance roles.

# 8. CONTROL EVIDENCE

Evidence shall be sufficient to demonstrate execution, timing, authority, outcome and exceptions without relying solely on undocumented assertions.

# 9. CONTROL FAILURE

A failed control shall trigger proportional assessment, containment, escalation, remediation and validation.

# 10. CONTROL ASSURANCE

Control assurance shall evaluate design adequacy, operating effectiveness, evidence quality and residual risk.

# 11. CONTROL AUTOMATION

Controls may be automated where automation preserves authority, traceability, deterministic behavior where required, exception handling and auditability.

# 12. AI CONTROL PRINCIPLE

AI may assist control monitoring and analysis, but AI-generated observations shall not be treated as authoritative control evidence without appropriate validation.

# 13. AGENT CONTROL PRINCIPLE

Agent authority, tools, data access, action scope, stop conditions and human escalation shall be explicitly controlled.

# 14. CONTROL MATURITY

Controls shall progress from ad hoc execution toward defined, measured, automated, adaptive and continuously improved operation.

# 15. CONTROL REGRESSION

A control shall be considered in regression when ownership, execution, evidence, effectiveness, coverage or assurance materially deteriorates.

**Effectiveness criteria:**

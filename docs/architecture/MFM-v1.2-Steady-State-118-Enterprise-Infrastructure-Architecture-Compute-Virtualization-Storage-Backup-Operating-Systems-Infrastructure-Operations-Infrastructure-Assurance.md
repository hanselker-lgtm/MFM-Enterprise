# 1. Purpose

This document establishes the one-hundred-and-eighteenth document in the MFM v1.2 Steady-State series.

It follows MFM v1.2-Steady-State-117 – Enterprise Network Architecture, Network Governance, Connectivity, Segmentation, Firewalling, DNS, Remote Access, Network Security & Network Assurance.

The purpose is to establish the permanent enterprise operating model for infrastructure strategy, infrastructure governance, compute architecture, physical servers, virtual machines, containers, operating systems, storage architecture, storage performance, backup, restore, infrastructure monitoring, infrastructure configuration, patching, infrastructure resilience, infrastructure capacity, infrastructure incidents, infrastructure changes, infrastructure lifecycle, infrastructure security integration, infrastructure suppliers, infrastructure compliance, infrastructure exceptions, remediation, infrastructure assurance, metrics, dashboards, maturity and continual enterprise infrastructure capability improvement.

The central objective is:

> **MFM must govern and operate compute, operating-system, virtualization, container and storage infrastructure as secure, resilient, recoverable and measurable enterprise capabilities supporting business services throughout their complete lifecycle.**

# 3. Infrastructure Governance Objective

The primary objective is:

> **Establish clear authority, ownership, architecture standards, operational responsibilities, security requirements, lifecycle controls and assurance for enterprise infrastructure.**

# 4. Infrastructure Architecture Objective

The primary objective is:

> **Provide reliable, scalable, secure and resilient infrastructure services aligned with enterprise business, application, data, network, cloud and security requirements.**

# 5. Compute Objective

The primary objective is:

> **Provide appropriately sized and governed compute resources capable of supporting required business services with defined availability, performance, capacity and recovery characteristics.**

# 6. Virtualization Objective

The primary objective is:

> **Provide controlled virtualization capabilities that improve resource utilization, operational consistency, resilience and recoverability without introducing unacceptable concentration or security risks.**

# 7. Storage Objective

The primary objective is:

> **Provide appropriately designed, protected and monitored storage capabilities meeting business requirements for capacity, performance, availability, integrity, recovery and lifecycle.**

# 8. Backup Objective

The primary objective is:

> **Protect critical infrastructure and data through reliable, secure and tested backup and recovery capabilities aligned with business recovery requirements.**

# 9. Infrastructure Assurance Objective

The primary objective is:

> **Provide evidence that infrastructure controls, configurations, capacity, resilience, backup, recovery and operational processes operate effectively.**

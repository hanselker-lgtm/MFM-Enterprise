# 1. PURPOSE

EA-IMETA-PRODUCTION-SERVICE-SECURITY-RESILIENCE-COMPLIANCE-IMPROVEMENT-01 establishes the controlled capability for improving the compliance environment beyond individual remediation.

The improvement chain is:

```text

 ↓

 ↓

 ↓

```

# 2. IMPROVEMENT PRINCIPLE

> EA-IMETA SHALL CONTINUOUSLY IMPROVE THE COMPLIANCE ENVIRONMENT THROUGH GOVERNED, EVIDENCE-BASED AND MEASURABLE CHANGES THAT REDUCE RISK, INCREASE CONTROL EFFECTIVENESS, IMPROVE RESILIENCE AND PREVENT RECURRENCE.

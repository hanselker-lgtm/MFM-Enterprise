# 1. Purpose

The purpose of the MFM Enterprise Architecture Application Reference Model is to establish a consolidated reference model describing Enterprise Applications across the complete MFM Enterprise Architecture Framework from EA-000 through EA-599.

The Application Reference Model shall provide:

- application identification
- application classification
- application ownership
- application relationships
- application service mapping
- application process mapping
- application lifecycle management
- architecture traceability

The model shall establish a common Enterprise language for defining, managing and evolving applications.

---

# 2. Scope

The Application Reference Model covers all MFM Enterprise Architecture application domains:

- Architecture Applications
- Business Applications
- Information Applications
- Data Applications
- Integration Applications
- Technology Applications
- Security Applications
- Governance Applications
- Ecosystem Applications
- Evolution Applications

The model applies to:

- strategic applications
- operational applications
- supporting applications
- enabling applications
- transformation applications
- evolution applications

---

# 3. Enterprise Application Architecture Principles

The Application Reference Model shall follow these principles.

---

## Business Alignment

Applications shall support Enterprise capabilities and business objectives.

---

## Service Enablement

Applications shall provide and consume Enterprise Services.

---

## Process Support

Applications shall enable controlled Enterprise Processes.

---

## Reusability

Applications shall be designed as reusable Enterprise assets.

---

## Standardization

Applications shall follow Enterprise technology and architecture standards.

---

## Lifecycle Management

Applications shall be managed throughout their complete lifecycle.

---

## Continuous Evolution

Applications shall continuously evolve according to Enterprise requirements.
